# PromptRefiner MVP

You are right to call this out: the previous scaffold was incomplete for a working Chrome install flow. This revision fixes that by adding the missing Plasmo/tooling setup and clearer install steps.

## Monorepo structure
- `apps/extension`: Plasmo Manifest V3 extension (React + TypeScript)
- `apps/api`: Express API for refinement + billing endpoints
- `apps/web`: web shell placeholder
- `packages/shared`: shared TypeScript contracts

## What works now (MVP)
- Detects textbox/contenteditable input and injects a floating **Refine** button.
- Host-aware adapters:
  - `ChatGPTAdapter`
  - `ClaudeAdapter`
  - `GeminiAdapter`
  - `GenericTextboxAdapter`
- Click flow: read draft → POST `/api/refine` → show modal → replace/copy/cancel.
- Refinement response contract:
  - `refinedPrompt`
  - `detectedIntent`
  - `missingContext`
  - `confidence`
- Free-tier guard scaffold: 10 refinements/user-id counter.
- Stripe checkout endpoint scaffold for yearly plan.
- Secret redaction prior to LLM call.

## Local setup (fixed Chrome extension flow)
1. Install dependencies at repo root:
   ```bash
   npm install
   ```
2. Run API:
   ```bash
   npm run dev:api
   ```
3. In another terminal run extension dev build:
   ```bash
   npm run dev:extension
   ```
4. Open Chrome and go to `chrome://extensions`.
5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select:
   - `apps/extension/build/chrome-mv3-dev` (for dev), or
   - `apps/extension/build/chrome-mv3-prod` (after production build).
8. Open `https://chatgpt.com`, `https://claude.ai`, or `https://gemini.google.com` and verify the **Refine** button appears near the input.

## Build a distributable zip
```bash
npm run build:extension
npm run package -w @promptrefiner/extension
```
Zip output is generated by Plasmo under `apps/extension/build/`.

## Supabase schema (target)
```sql
create table users (
  id uuid primary key,
  email text not null unique,
  stripe_customer_id text,
  subscription_status text default 'free',
  plan text default 'free',
  created_at timestamptz default now()
);

create table usage_events (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references users(id),
  refinement_count int not null default 0,
  month text not null,
  created_at timestamptz default now()
);

create table prompt_preferences (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references users(id),
  default_mode text default 'default',
  custom_style_instruction text,
  allow_prompt_history boolean default false,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);
```

## Security notes
- No hardcoded API keys (env only).
- Raw prompt storage is off by default.
- Optional `allow_prompt_history` should gate any prompt persistence.
- Add distributed rate limiting (Redis/Upstash) before production.
- Add Stripe webhook signature validation before production.
